5-minute quick start

  1. 1

    Add the URLs you want to test

    Open Sites tab → paste a site's homepage URL into the Discover pages field → click Discover pages →. The tool reads sitemap.xml and lets you tick which pages to add. Press Save.

  2. 2

    Pick what to run

    On the Run tab, tick at least one test type. Site audit gives you the broadest overview (Screaming Frog–style report); the others target specific concerns (Functional, Visual, A11y, etc.). When Site audit is the only one ticked, the rest of the form is auto-disabled — audit is a standalone crawler.

  3. 3

    Choose where to test

    Three Configs: Local (Playwright on your machine — fast, free) · Real Device Emulation (DevTools-grade — touch, real DPR, real Chrome/Safari channels, video on every test) · BrowserStack (real Windows / macOS desktop browsers via cloud).

    ⚠ BrowserStack Playwright Web Automate doesn't support real iOS / Android (it's a BS product limit). For mobile/tablet, use Real Device Emulation.

  4. 4

    Run, watch the log, read the report

    Press ▶ Run tests. The log streams live. After the run a Failures tab appears with bug-report cards (project, scenario, expected vs received, inline screenshots), and three download buttons: ↓ CSV / XLSX / PDF. Site audits open as filterable HTML in the Reports tab.
